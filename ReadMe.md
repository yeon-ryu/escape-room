### 객체 지향 설계
- 추상화 : `ROOM` 추상 클래스로 게임 승리/패배 시의 공통 동작 정의
- 상속 & 다형성 : 미니 게임 방들이 `ROOM` 을 상속받아 플레이와 룰 설명을 각각 다르게 동작
- 캡술화 : 플레이어의 정보를 private 로 보호하고 열쇠, 재도전 횟수 관리 등을 메소드를 통해 조작

### 디자인 패턴
- 싱글톤 : GameManager 는 프로젝트에 하나만 존재해야 하므로 싱글톤으로 구성

### 확장성
- 미니 게임 방 갯수를 MAX_ROOM 으로 작성하여 유동적으로 쉽게 미니게임을 추가할 수 있는 구성이 되도록 작성
